# Datos

Este proyecto usa **BACI** (CEPII), versión HS92 V202601.

1. Descárgalo desde la página del CEPII (busca "BACI" en cepii.fr).
2. Descomprímelo dentro de esta carpeta, de modo que quede:

   data/BACI_HS92_V202601/
   ├── BACI_HS92_Y2021_V202601.csv
   ├── BACI_HS92_Y2022_V202601.csv
   ├── BACI_HS92_Y2023_V202601.csv
   ├── country_codes_V202601.csv
   └── product_codes_HS92_V202601.csv

Los datos pertenecen al CEPII y tienen sus propias condiciones de uso;
por eso no se incluyen en este repositorio.
